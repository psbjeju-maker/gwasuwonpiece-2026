# 황금 귤을 찾아라 — 사용 설명

행사장 QR 보물찾기 게임. **앱 설치 없이 모바일 웹**으로 돌아간다.
지금은 Firebase 없이 **각 폰 안에서만** 동작하는 상태다 (플레이·테스트는 완전히 가능).

---

## 1. 바로 열어보기

Desktop 폴더에서 `serve.py`를 켠 다음:

| 화면 | 주소 |
|---|---|
| 참가자 | http://localhost:8000/과수원피스_할로윈_1031/game/ |
| 운영자 | http://localhost:8000/과수원피스_할로윈_1031/game/admin.html |
| QR 하나 테스트 | 위 주소 뒤에 `?q=A01` |

운영자 PIN은 **6842** (운영자 화면 → 최종 정답 탭에서 변경 가능).

---

## 2. 파일이 하는 일

| 파일 | 내용 |
|---|---|
| `index.html` | 참가자 화면 전부 (등록 → 퀴즈 → 지도 → 최종 → 쿠폰) |
| `admin.html` | 운영자 화면 (진행현황·정답설정·퀴즈편집·QR목록·데이터) |
| `data.js` | **여기가 콘텐츠다.** QR 40개, 퀴즈 41문제, 최종 정답, 구역 정보 |
| `app.js` | 게임 로직 |
| `store.js` | 저장 담당. Firebase를 붙이는 자리도 여기 |
| `style.css` | 참가자 화면 디자인 |
| `sw.js` | 오프라인 대응 (한 번 열어두면 신호 없어도 QR이 열림) |
| `make_qr.py` | QR 인쇄 시트 만드는 스크립트 |
| `out/` | 만들어진 QR 이미지와 인쇄 시트 |

## 3. 내용 바꾸기 — 두 가지 방법

### 방법 A. 운영자 화면에서 (권장)
1. `admin.html` 열기 → PIN 입력
2. **최종 정답** 탭에서 정답 문장을 바꾸면 글자가 자동으로 QR에 배정된다
3. **퀴즈** 탭에서 문제와 정답을 고친다
4. 다 고쳤으면 **데이터** 탭 → `data.js 내려받기`
5. 받은 파일로 이 폴더의 `data.js`를 덮어쓴다 → 모든 폰에 반영

> 운영자 화면에서 고친 내용은 **그 브라우저에만** 저장된다.
> 4~5번을 해야 다른 기기에도 반영된다.

### 방법 B. `data.js`를 직접 편집
메모장으로 열어서 고쳐도 된다. 구조는 파일 안 주석에 적어뒀다.

## 4. 지금 들어있는 샘플 콘텐츠

- **최종 정답**: `제주에서제일달콤한황금 귤` (13자) — 임시다. 실제 정답으로 바꿀 것
- **퀴즈 40문제**: 애니·서브컬처 쉬운 문제. 정답 별칭이 문제당 2~6개 들어있다
- **QR 40개**: 고유 글자 13 + 백업 10 + 이벤트 17

**백업 QR**은 원본과 **다른 구역**에 두도록 배정했다. 산책로(E)·꽃길(F)·비닐하우스(G) 글자는 전부 접근 쉬운 A·C·D 구역에 사본이 있다.
백업이 없는 글자는 3개(`서`=B04, `달`=D01, `콤`=D04)인데, 셋 다 사람이 많이 지나는 자리라 훼손돼도 바로 눈에 띈다.

## 5. QR 인쇄물 만들기

```
python make_qr.py https://실제주소/
```

- `out/인쇄시트_01~07.png` — A4에 6장씩, 총 7장. 그대로 인쇄해서 오려 쓴다
- `out/qr/A01.png` — 낱장. 한 장만 다시 뽑을 때

카드에는 QR·구역명·"카메라로 찍으세요"·"안 열리면 스태프에게"가 들어간다.
오른쪽 아래 작은 코드(A01 등)는 **스태프 식별용**이다.

> 주소가 바뀌면 QR도 전부 다시 뽑아야 한다. **주소를 먼저 확정하고 인쇄할 것.**

## 6. 아직 안 된 것 (Firebase)

지금은 **폰마다 따로** 저장된다. 그래서:

| 되는 것 | 안 되는 것 |
|---|---|
| 참가자가 혼자 처음부터 끝까지 플레이 | 운영자 화면에서 **다른 폰** 참가자 보기 |
| 오프라인에서도 게임 진행 | 폰을 바꿨을 때 이어하기 |
| 쿠폰 발급·번호 부여 | 여러 스태프가 같은 현황판 보기 |

붙이는 법: `store.js` 맨 위 `var FIREBASE = null;` 에 설정값을 넣고, 그 아래 `flush()` 안에 Firestore 저장 코드를 채우면 된다. **게임 코드(app.js)는 손댈 필요 없다.**

기존 `psbjeju-kuji` 프로젝트를 그대로 써도 되고, 새로 만들어도 된다.

## 7. 행사 당일 순서

1. 개장 전 — QR 40장 부착, 위치를 운영자 화면 QR 목록과 대조
2. 스태프 폰에 `admin.html` 열어두기 (PIN 공유)
3. QR이 떨어졌다 → **진행 현황** 탭에서 단서 수동 지급
4. 참가자가 쿠폰 화면을 보여주면 → **지급** 버튼
5. 문제가 생기면 → 우측 상단 **게임 일시중지**
6. 행사 후 — **데이터** 탭에서 참가자 CSV 받고, **전체 참가자 데이터 삭제**

> 6번은 꼭 한다. 이름·전화번호가 저장되어 있고, 등록 화면에서 "7일 내 삭제"를 약속했다.
