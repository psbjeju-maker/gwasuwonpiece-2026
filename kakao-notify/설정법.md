# 셀러/무대 신청 → 카톡 알림 설정법

부스나 무대 신청이 들어올 때마다 사장님 카카오톡(나에게 보내기)으로 알림이 오게 만드는 설정입니다.
**사업자 등록이나 카카오 비즈니스 계정, 알림톡 심사 같은 건 전혀 필요 없습니다** — 개인 카카오 계정으로 5분이면 끝납니다.
전부 사장님이 직접 로그인해서 눌러야 하는 단계라(클로드가 대신 로그인할 수 없음), 아래 순서대로만 따라오시면 됩니다.

---

## 1단계 — 카카오 개발자 앱 만들기

1. https://developers.kakao.com 접속 → 카카오 계정으로 로그인
2. 상단 "내 애플리케이션" → "애플리케이션 추가하기"
3. 앱 이름: 아무거나 (예: `과수원피스알림`) → 저장
4. 앱을 열면 왼쪽 메뉴에 **"요약 정보"**가 보임 → 여기서 **REST API 키**를 복사해서 어딘가에 메모 (2단계에서 씀)

## 2단계 — 카카오 로그인 + 동의항목 켜기

1. 왼쪽 메뉴 **"카카오 로그인"** → 활성화 **ON**
2. 같은 화면의 **"Redirect URI"**에 아래 값을 등록:
   ```
   https://developers.kakao.com/tool/demo/oauth
   ```
   (이건 카카오가 제공하는 테스트용 페이지라 우리가 따로 서버를 안 만들어도 됨)
3. 왼쪽 메뉴 **"동의항목"** → **"카카오톡 메시지 전송"** 항목을 찾아서 **필수 동의**로 설정
   - "나에게 보내기"는 별도 심사 없이 바로 사용 가능합니다.

## 3단계 — 인가코드 받기 (로그인 인증)

1. 아래 주소에서 `{REST_KEY}` 부분을 1단계에서 복사한 REST API 키로 바꿔서 브라우저 주소창에 붙여넣고 이동:
   ```
   https://kauth.kakao.com/oauth/authorize?client_id={REST_KEY}&redirect_uri=https://developers.kakao.com/tool/demo/oauth&response_type=code&scope=talk_message
   ```
2. 카카오 로그인 화면이 뜨면 로그인 → "동의하고 계속하기"
3. `https://developers.kakao.com/tool/demo/oauth?code=xxxxxxxxxx...` 같은 주소로 이동됨
   → 주소창의 **`code=` 뒤에 있는 긴 문자열**을 복사 (이게 인가코드, **10분 안에** 써야 함)

## 4단계 — Google Apps Script에 붙여넣기

1. https://script.google.com 접속 → 로그인 → "새 프로젝트"
2. 기본으로 열려있는 `Code.gs`의 내용을 전부 지우고, 이 폴더의 **`Code.gs` 파일 내용을 그대로 복사해서 붙여넣기**
3. 붙여넣은 코드에서 `최초설정_실행하세요` 함수 안의 세 값을 채우기:
   - `REST_KEY`: 1단계에서 복사한 REST API 키
   - `REDIRECT_URI`: 그대로 둬도 됨 (2단계와 동일한 값)
   - `AUTH_CODE`: 3단계에서 복사한 인가코드
4. 상단 함수 선택 드롭다운에서 **`최초설정_실행하세요`** 선택 → ▶ 실행 버튼 클릭
   - 처음 실행하면 권한 승인 창이 뜸 → 본인 계정 선택 → "고급" → "이동(안전하지 않음)" → 허용
   - 실행이 끝나면 하단 "실행 기록"에서 로그 확인 — "저장 완료!" 문구가 보이면 성공
5. 함수 드롭다운에서 **`testSend`** 선택 → 실행 → **카카오톡 확인** (본인에게 온 메시지 확인되면 성공)

## 5단계 — 웹앱으로 배포

1. Apps Script 화면 우측 상단 **"배포"** → **"새 배포"**
2. 유형 선택(톱니바퀴) → **"웹 앱"**
3. 실행 계정: **나(본인)**, 액세스 권한: **모든 사용자** 로 설정 → "배포"
4. 나오는 **웹 앱 URL**을 복사 (`https://script.google.com/macros/s/xxxxx/exec` 형태)

## 6단계 — 사이트에 웹앱 URL 연결

`game/apply-core.js` 파일 맨 위쪽 `KAKAO_WEBHOOK_URL = ""` 부분에, 5단계에서 복사한 웹앱 URL을 따옴표 안에 붙여넣기:

```js
var KAKAO_WEBHOOK_URL = "https://script.google.com/macros/s/xxxxx/exec";
```

저장 후 커밋·푸시하면 끝 — 이후 부스/무대 신청이 들어올 때마다 사장님 카톡으로 바로 알림이 옵니다.
(이 URL 채워넣는 것과 커밋/푸시는 클로드가 대신 해드릴 수 있습니다 — URL만 알려주시면 됩니다.)

---

## 참고
- refresh token은 카카오 기준 보통 두 달 정도 유효합니다. 어느 날 갑자기 알림이 안 오면, 3~4단계(인가코드 받기 → `최초설정_실행하세요` 재실행)만 다시 하면 됩니다.
- 알림 실패는 신청 접수 자체와 완전히 분리돼 있어서, 혹시 이 설정이 잘못돼도 신청서 제출 자체는 항상 정상 작동합니다.
- 무대(`apply-stage.html`) 신청도 같은 방식으로 알림이 갑니다 — 따로 설정할 필요 없음.
